# Finding the Hypotenuse of a Right Triangle Using the Math Library

## Description
This program calculates the hypotenuse of a right triangle using the numbers you input.

## How to Run
1. Open the program file in VS Code, Replit, or Google Colab.

2. Run the program.

3. Enter the values for a and b.

4. Check the length of the hypotenuse displayed on the screen.

## Input Needed
- a = The first shorter side of the triangle 
- b = The second shorter side of the triangle 

## Sample Output
Enter length of the first shorter side 3

Enter length of the second shorter side 5

Hypotenuse is  5.83
